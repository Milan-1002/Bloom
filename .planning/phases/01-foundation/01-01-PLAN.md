| Boundary | Description |
|----------|-------------|
| localStorage → app | Theme preference read on startup; values are constrained to known palettes ('slate'|'warm'|'sage') |
| env vars → Vite bundle | VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY are bundled into client JS; anon key is safe to expose (RLS protects data) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | localStorage (theme keys) | accept | Theme values are cosmetic only; worst case is wrong palette display. Validate palette value against known list in loadTheme() — invalid values fall back to 'slate'. |
| T-01-02 | Information Disclosure | VITE_SUPABASE_ANON_KEY in bundle | accept | Anon key is public by Supabase design; RLS policies (plan 01-02) enforce data isolation. Never put service_role key in Vite env. |
| T-01-SC | Tampering | npm package installs | mitigate | All packages in RESEARCH.md Package Legitimacy Audit verified via npm registry 2026-05-18. No [ASSUMED] or [SUS] packages. |
</threat_model>
