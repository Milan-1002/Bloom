# Plan 03-01: Symptom Logging

## Goal

A user can open the Symptoms tab, select a date (today or a past day), rate energy / mood / sleep / bloating / skin on a 1–5 scale, and save. The entry is UPSERTed into symptom_logs (one row per user per date). Today's logged symptoms appear as a summary card on the HomeScreen dashboard.

## Context

- **Schema:** `symptom_logs` — `user_id`, `log_date` (date), `logged_at`, `energy`, `mood`, `sleep`, `bloating`, `skin` (all 1–5 nullable). Unique constraint: `(user_id, log_date)`.
- **Dates:** `log_date` is an explicit `YYYY-MM-DD` string set by the client — same pattern as `weight_logs`/`symptom_logs` from Phase 1.
- **02-05 built:** `DateStrip` component + `toLocalDateStr()` — reused here.
- **AppLayout:** currently 3 tabs (Home | Diary | Profile) — adding Symptoms (4 tabs total).

## Symptom definitions

| key | label | color token | lower=better? |
|-----|-------|-------------|---------------|
| energy | Energy | `--b-mint` | no |
| mood | Mood | `--b-accent` | no |
| sleep | Sleep quality | `--b-primary` | no |
| bloating | Bloating | `--b-coral` | yes |
| skin | Skin · acne | `--b-amber` | yes |

## Threat Model

| ID | Threat | Mitigation |
|----|--------|------------|
| T-03-01-01 | UPSERT another user's symptom_log | RLS `(select auth.uid()) = user_id` blocks cross-user writes; `user_id` hardcoded to `user!.id` in mutation |
| T-03-01-02 | Symptom value outside 1–5 | Input UI only allows tapping 1–5 integers; no free-text entry |

**GREEN:** `src/hooks/useSymptomLog.ts` + `src/hooks/useUpsertSymptomLog.ts`

`useSymptomLog`:
```ts
export function useSymptomLog(dateStr: string) {
  return useQuery({
    queryKey: ['symptom-log', dateStr],
    queryFn: async () => {
      const { data, error } = await supabase
        .from('symptom_logs')
        .select('*')
        .eq('log_date', dateStr)
        .maybeSingle()
      if (error) throw error
      return data as Tables<'symptom_logs'> | null
    },
    staleTime: 30 * 1000,
  })
}
```

`useUpsertSymptomLog`:
```ts
export function useUpsertSymptomLog() {
  const { user } = useAuth()
  const queryClient = useQueryClient()
  return useMutation({
    mutationFn: async (payload: SymptomPayload) => {
      const { error } = await supabase.from('symptom_logs').upsert({
        user_id: user!.id,
        log_date: payload.log_date,
        energy: payload.energy,
        mood: payload.mood,
        sleep: payload.sleep,
        bloating: payload.bloating,
        skin: payload.skin,
        logged_at: new Date().toISOString(),
      }, { onConflict: 'user_id,log_date' })
      if (error) throw error
    },
    onSuccess: (_, payload) => {
      queryClient.invalidateQueries({ queryKey: ['symptom-log', payload.log_date] })
    },
  })
}
```

**Form state management:**
```tsx
const [selectedDate, setSelectedDate] = useState(toLocalDateStr())
const { data: savedLog, isFetching } = useSymptomLog(selectedDate)
const [values, setValues] = useState({ energy: 0, mood: 0, sleep: 0, bloating: 0, skin: 0 })
const [showSaved, setShowSaved] = useState(false)
const upsert = useUpsertSymptomLog()

// Sync form with DB when date/savedLog changes
useEffect(() => {
  if (!isFetching) {
    setValues({
      energy: savedLog?.energy ?? 0,
      mood: savedLog?.mood ?? 0,
      sleep: savedLog?.sleep ?? 0,
      bloating: savedLog?.bloating ?? 0,
      skin: savedLog?.skin ?? 0,
    })
  }
}, [savedLog, isFetching])

const hasAnyValue = Object.values(values).some(v => v > 0)
const hasChanges = savedLog
  ? Object.keys(values).some(k => values[k] !== (savedLog[k] ?? 0))
  : hasAnyValue

const handleSave = async () => {
  if (!hasAnyValue) return
  await upsert.mutateAsync({ log_date: selectedDate, ...values })
  setShowSaved(true)
  setTimeout(() => setShowSaved(false), 2000)
}
```
