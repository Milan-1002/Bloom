## What Was Built

### src/lib/report-pdf.tsx

react-pdf Document component for the full health report:

- `ReportDocument` exported component takes `{ chartImageUrl, stats, windowDays, generatedAt }` props
- `ReportDocumentProps` interface exported for typed usage in dynamic import context
- A4 page layout with padding 40, Helvetica font, `#f8f7ff` background
- **Header:** "Bloom Health Report" title in `#8b5cf6` violet, subtitle with window + generated date + days with data
- **Summary section:** Row of stat boxes (Avg Daily GL, Avg Fiber, Weight Change, conditional Cycle Length)
- **Chart section:** `<Image src={chartImageUrl}>` embeds the html2canvas PNG — react-pdf does not support Recharts SVG directly
- **Red-flag section:** Conditional — only rendered when `stats.redFlagStreaks.length > 0`; coral-bordered box listing each streak period with dates, days count, and avg overage %
- **Meal patterns section:** Eating window, first/last meal times, fasting window, slot distribution percentages (Breakfast/Lunch/Dinner/Snack)
- **Footer:** "Generated by Bloom — PCOS Nutrition Companion · {generatedAt}" at absolute bottom
- Hex colour constants (`const C = {...}`) — required because CSS variables are unavailable in react-pdf render context

### src/screens/report/ReportScreen.tsx (changes only)

Targeted additions on top of Plan 02 output:

- `import { toLocalDateStr } from '@/lib/dates'` — used for PDF filename and `generatedAt` prop
- `const [isExporting, setIsExporting] = useState(false)` — loading state
- `SpinnerIcon()` sub-component — animated spin div with `border-b-primary`
- `handleExport()` async function:
  1. Guard: returns early if `!stats || !chartRef.current || isExporting`
  2. `html2canvas(chartRef.current, { scale: 2, useCORS: true, logging: false, backgroundColor: '#ffffff' })` → PNG data URL
  3. Dynamic `import('@react-pdf/renderer')` + `import('@/lib/report-pdf')` → avoids bundling ~2MB at initial load
  4. `pdf(<ReportDocument .../>).toBlob()` → PDF Blob
  5. Filename: `bloom-report-${windowDays}d-${toLocalDateStr()}.pdf`
  6. `navigator.canShare({files})` check → native share sheet; otherwise programmatic `<a download>`
  7. `setTimeout(() => URL.revokeObjectURL(blobUrl), 30_000)` — memory cleanup
  8. `catch` logs error; `finally` always resets `isExporting`
- AppBar trailing prop updated: `div` wrapper with `pointer-events-none opacity-50` when exporting, `SpinnerIcon`/`ShareIcon` toggle, `onClick={handleExport}`
