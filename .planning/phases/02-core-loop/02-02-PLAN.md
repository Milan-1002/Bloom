# Plan 02-02: Food Logging

## Goal

A user who selected a food from the USDA search results lands on FoodDetailScreen, adjusts the serving size and meal slot, and taps "Add to [Slot]" to insert a denormalized `food_logs` row — then returns to /home.

## Context

- **02-01 built:** `src/lib/gl.ts` (calculateGL / formatGL / lookupGIForDisplay), `src/lib/usda.ts` (getFoodByFdcId, scaleMacros), `src/hooks/useFoodSearch.ts`, `FoodSearchScreen` at `/log?slot=<slot>` — navigates to `/log/detail/:fdcId?slot=<slot>` on food select.
- **App.tsx stub:** `const FoodDetailScreen = () => null` at route `/log/detail/:fdcId` — wire the real screen in Task 3.
- **Schema:** `food_logs` has: `user_id`, `fdc_id`, `food_name`, `meal_slot`, `serving_g`, `logged_at`, `kcal`, `protein_g`, `carbs_g`, `fat_g`, `fiber_g`, `sugar_g`, `gi`, `gl`.
- **Design reference:** `bloom-app-design/project/screens/Logging.jsx` — `FoodDetail` component (state 3).

## Threat Model

| ID | Threat | Mitigation |
|----|--------|------------|
| T-02-02-01 | User logs food against another user's account | INSERT payload sets `user_id` from `useAuth().user.id` — server RLS enforces `(select auth.uid()) = user_id` |
| T-02-02-02 | Negative / zero serving_g sent to DB | Client enforces `serving_g >= 1` with stepper min constraint |
| T-02-02-03 | GL stored as 0 when GI unknown | `calculateGL` returns `null` for unknown GI — INSERT uses `null`, never `0` |

**GREEN commit:** `src/hooks/useLogFood.ts`

```ts
import { useMutation, useQueryClient } from '@tanstack/react-query'
import { supabase } from '@/lib/supabase'
import { useAuth } from '@/hooks/useAuth'

interface LogFoodPayload {
  fdc_id: string
  food_name: string
  meal_slot: string
  serving_g: number
  kcal: number | null
  protein_g: number | null
  carbs_g: number | null
  fat_g: number | null
  fiber_g: number | null
  sugar_g: number | null
  gi: number | null
  gl: number | null
}

export function useLogFood() {
  const { user } = useAuth()
  const queryClient = useQueryClient()

  return useMutation({
    mutationFn: async (payload: LogFoodPayload) => {
      const { error } = await supabase.from('food_logs').insert({
        user_id: user!.id,
        fdc_id: payload.fdc_id,
        food_name: payload.food_name,
        meal_slot: payload.meal_slot,
        serving_g: payload.serving_g,
        logged_at: new Date().toISOString(),
        kcal: payload.kcal,
        protein_g: payload.protein_g,
        carbs_g: payload.carbs_g,
        fat_g: payload.fat_g,
        fiber_g: payload.fiber_g,
        sugar_g: payload.sugar_g,
        gi: payload.gi,
        gl: payload.gl,
      })
      if (error) throw error
    },
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['food-logs'] })
    },
  })
}
```

### Task 2 — `FoodDetailScreen`

**Commit:** `src/screens/logging/FoodDetailScreen.tsx`

Key behaviors:
- Reads `:fdcId` from route params and `?slot=` from search params.
- Loads food via `getFoodByFdcId(fdcId)` (TanStack Query, staleTime=5m, queryKey `['usda-food', fdcId]`).
- **Serving stepper:** state `servingG`, initialized to 100, step ±25, min 1. Minus button disabled at min.
- **Meal slot picker:** 4 Chip buttons (Breakfast / Lunch / Dinner / Snack). Active chip uses `tone="primary"`, inactive uses `tone="ghost"`.
- **Macros display:** `scaleMacros(food, servingG)` recomputed on every servingG change. Ring shows kcal (max=2000). MacroPill grid: Protein / Carbs / Fat / Fiber.
- **PCOS panel:** GL (via `calculateGL(food.description, carbs_g_scaled)`, formatted via `formatGL`), added sugar (scaled), GI (from `lookupGIForDisplay` — show "—" if null).
- **CTA button:** "Add to [Slot] · X kcal" where X = scaled kcal rounded. Disabled while loading or mutating. On tap: calls `logFood.mutateAsync(...)`, then `navigate('/home', { replace: true })`.
- **Loading state:** spinner while `isFetching` (same animated spinner style as FoodSearchScreen).
- **Error state:** "Could not load food. Go back." with back-nav link.
