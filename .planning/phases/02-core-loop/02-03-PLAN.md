# Plan 02-03: Barcode Scan

## Goal

A user on the food search screen taps the scan icon and lands on BarcodeScanScreen. The camera activates, detects a barcode, looks up the UPC in the `usda_foods` cache, and either navigates to FoodDetailScreen (cache hit) or shows a first-class manual search fallback (cache miss). Camera unavailable / permission denied shows a clear fallback too.

## Context

- **02-01 built:** `getFoodByBarcode(gtin)` in `usda.ts` — queries `usda_foods` by `gtin_upc`, returns `USDAFood | null`.
- **02-02 built:** FoodDetailScreen at `/log/detail/:fdcId?slot=<slot>` — the landing after a successful scan.
- **App.tsx stub:** `const BarcodeScanScreen = () => null` at `/log/scan` — wire real screen in Task 3.
- **CLAUDE.md note:** "iOS Safari barcode scan confidence is MEDIUM — fallback to manual entry must be first-class UX."
- **Library:** `html5-qrcode` — listed in CLAUDE.md tech stack, not yet installed.
- **Barcode normalization:** USDA FoodData Central stores GTINs zero-padded to 14 digits. EAN-13 (13 digits) and UPC-A (12 digits) scans must be left-padded to 14 before cache lookup.

## Threat Model

| ID | Threat | Mitigation |
|----|--------|------------|
| T-02-03-01 | Camera stream not cleaned up on unmount | useEffect cleanup calls `scanner.stop()` + `scanner.clear()` |
| T-02-03-02 | Multiple callbacks fired per barcode frame | `hasScannedRef.current` guard — only first callback proceeds |
| T-02-03-03 | Permission denied leaves user stranded | Error state always shows "Search manually" CTA navigating to /log |

### Task 1 — `useFoodByBarcode` hook (TDD: RED → GREEN)

**RED commit:** `tests/logging/use-food-by-barcode.test.tsx` (3 tests, all failing — module not found).

```ts
// tests/logging/use-food-by-barcode.test.tsx
import { renderHook, waitFor } from '@testing-library/react'
import { describe, it, expect, vi } from 'vitest'
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'
import { createElement } from 'react'

const mockGetFoodByBarcode = vi.hoisted(() => vi.fn())
vi.mock('@/lib/usda', () => ({
  getFoodByBarcode: mockGetFoodByBarcode,
}))

import { useFoodByBarcode } from '@/hooks/useFoodByBarcode'

function wrapper({ children }: { children: React.ReactNode }) {
  const qc = new QueryClient({ defaultOptions: { queries: { retry: false } } })
  return createElement(QueryClientProvider, { client: qc }, children)
}

describe('useFoodByBarcode', () => {
  it('does not call getFoodByBarcode when upc is null', () => {
    renderHook(() => useFoodByBarcode(null), { wrapper })
    expect(mockGetFoodByBarcode).not.toHaveBeenCalled()
  })

  it('calls getFoodByBarcode with the provided upc and returns the food', async () => {
    const mockFood = { fdc_id: 'fdc-1', description: 'Greek Yogurt', gtin_upc: '00012345678901' }
    mockGetFoodByBarcode.mockResolvedValue(mockFood)
    const { result } = renderHook(() => useFoodByBarcode('00012345678901'), { wrapper })
    await waitFor(() => expect(result.current.isSuccess).toBe(true))
    expect(mockGetFoodByBarcode).toHaveBeenCalledWith('00012345678901')
    expect(result.current.data?.fdc_id).toBe('fdc-1')
  })

  it('returns null when barcode not found in cache (cache miss)', async () => {
    mockGetFoodByBarcode.mockResolvedValue(null)
    const { result } = renderHook(() => useFoodByBarcode('00099999999999'), { wrapper })
    await waitFor(() => expect(result.current.isSuccess).toBe(true))
    expect(result.current.data).toBeNull()
  })
})
```

**GREEN commit:** `src/hooks/useFoodByBarcode.ts`

```ts
import { useQuery } from '@tanstack/react-query'
import { getFoodByBarcode } from '@/lib/usda'

export function useFoodByBarcode(upc: string | null) {
  return useQuery({
    queryKey: ['barcode-food', upc],
    queryFn: () => getFoodByBarcode(upc!),
    enabled: upc !== null && upc.length > 0,
    staleTime: 10 * 60 * 1000,
    retry: 0,
  })
}
```

#### Screen states

| State | What user sees |
|-------|---------------|
| `starting` | Dark screen, spinner, "Initializing camera…" |
| `scanning` | Live camera feed, reticle (corner brackets + scan line), "Search manually" bottom strip |
| `looking-up` | Camera feed frozen, spinner overlay, "Looking up product…" |
| `not-found` | Dark overlay: "Product not found" + two buttons: "Search by name" / "Scan again" |
| `error` | Dark screen, error message, "Search by name" CTA |

#### UPC normalization

```ts
function normalizeUpc(raw: string): string {
  return raw.replace(/\D/g, '').padStart(14, '0')
}
```

Handles EAN-13 (13 digits → pad to 14) and UPC-A (12 digits → pad to 14).

#### Camera integration (html5-qrcode)

- Static import: `import { Html5Qrcode } from 'html5-qrcode'`
- Target div: `<div id="barcode-reader" className="absolute inset-0 overflow-hidden" />`
- Inject CSS to make the library's `<video>` fill the container:
  ```tsx
  <style>{`#barcode-reader video { width:100%!important; height:100%!important; object-fit:cover!important; } #barcode-reader canvas { display:none!important; }`}</style>
  ```
- `fps: 10`, `qrbox: { width: 280, height: 160 }` — wide landscape reticle
- `hasScannedRef` guards against multiple callbacks per frame
- Cleanup: `scanner.stop().catch(() => {}).finally(() => scanner.clear())`

#### Scan flow

```
onScanSuccess(rawText)
  → stop scanner
  → normalizeUpc(rawText)
  → setScannedUpc(normalized)   ← triggers useFoodByBarcode query
  → setStatus('looking-up')

useEffect watching [food, isFetching, scannedUpc]:
  if isFetching → wait
  if food       → navigate('/log/detail/:fdcId?slot=', { replace: true })
  if !food      → setStatus('not-found')
```
